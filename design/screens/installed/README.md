# Real pictures from an installed system

These are **real**: SIX's installer and its disk unlock prompt, photographed from a test computer
(a virtual machine with a 1024 × 768 screen) on 15 November 2026, while SIX was installed on an
empty, encrypted disk and then started. They are cropped to the screen and not otherwise changed.
The account in them ("tester") is a throwaway test account.

| Picture | What it shows |
|---|---|
| [`installer-1-language.png`](installer-1-language.png) | Step 1 of 5, Language: "Welcome to SIX", the languages, the keyboard hint, "Accessibility and appearance" |
| [`installer-3-where-six-goes.png`](installer-3-where-six-goes.png) | Step 3, Where SIX goes: the method, the chosen drive, disk encryption on by default, and the note that stops Next until a passphrase is typed |
| [`installer-4-your-account.png`](installer-4-your-account.png) | Step 4, Your account: name, sign-in name, administrator, password and its strength, computer name, "Disk encryption: On" |
| [`installer-5-review.png`](installer-5-review.png) | Step 5, Review and install: everything that will happen, each with Change; **Install SIX** as the main button |
| [`installer-6-installing.png`](installer-6-installing.png) | Installing SIX: four stages with Done, Now and Waiting, the bar, and the minutes passed in the long stage |
| [`installer-7-installed.png`](installer-7-installed.png) | The end: every stage done, "SIX is installed. Press Restart to start using it." |
| [`sign-in.png`](sign-in.png) | The sign-in screen after start-up: the clock, the account, the password field (empty), **Sign in**, Switch user, and Accessibility, the session, Sleep, Restart, Shut down along the foot; behind it Noir Instrument, darkened |
| [`disk-unlock.png`](disk-unlock.png) | The disk unlock prompt at start-up: the Hex Face, "Unlock this disk", the field with its padlock, the keyboard layout |

Step 2 (Basic settings) and the desktop of that system are not included: step 2 shows the test
computer's own region and time zone, and the desktop's dock carried another company's logo.
