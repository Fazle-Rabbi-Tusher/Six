# A real picture from an installed system

This one is **real**: SIX's disk unlock prompt, photographed from a test computer (a virtual
machine with a 1024 × 768 screen) on 15 November 2026, while SIX was starting from an empty,
encrypted disk it had just been installed on. It is cropped to the screen and not otherwise changed.

| Picture | What it shows |
|---|---|
| [`disk-unlock.png`](disk-unlock.png) | The disk unlock prompt at start-up: the Hex Face, "Unlock this disk", the field with its padlock, the keyboard layout |

The installer's pages and the sign-in screen were photographed the same way on 15 November. Their
words and edges have changed since, and no newer installed system has been photographed, so those
pictures were replaced by pictures drawn by SIX's real sign-in, lock and installer code at the
desk: [`../system/`](../system/README.md).
