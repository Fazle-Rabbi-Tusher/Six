# Wallpapers

Six of the seven picture wallpapers SIX has, chosen in Settings › Wallpaper. They are generated
artwork made for SIX. Each file here is the original, unchanged. The seventh, Chrome Bloom (dark),
is not in this folder.

| File | Name in SIX | Tone | Where SIX uses it by default |
|---|---|---|---|
| [`paper-tide.png`](paper-tide.png) | Paper Tide | light | **Home in light** |
| [`ion-drift.png`](ion-drift.png) | Ion Drift | dark | **Home in dark**, and the **lock screen** |
| [`noir-instrument.png`](noir-instrument.png) | Noir Instrument | dark | Behind the **sign-in screen**, darkened |
| [`blueprint-flow.png`](blueprint-flow.png) | Blueprint Flow | light | |
| [`silver-current.png`](silver-current.png) | Silver Current | light | |
| [`six-glitch.png`](six-glitch.png) | SIX Glitch | dark | |

Every file is **1672 × 941 pixels**. SIX never upscales them: on a larger screen it fills, fits or
centres the picture as the person chooses, but does not make a bigger copy.

Besides these, SIX has **Matte** (a plain light or dark ground, the fallback), the five wallpapers
drawn live by home's shader (Obsidian, Signal, Contour, Strata, Velvet; [04](../guide/04-color.md#wallpapers)),
and in the Sculpted design a tonal ground with SIX embossed in it, when Matte is chosen. A person can
add their own pictures too.
